# Simple Interest Calculator

A small Bash program that calculates simple interest from a principal amount, an annual interest rate, and a time period in years. It also prints the total principal plus interest.

## Run

```bash
bash simple-interest.sh
```

Enter nonnegative numeric values when prompted. Interest is calculated as `principal × rate × time / 100`.
